# 币安成交对账

NOFX 启动后为配置中的币安实盘 trader 执行一次同步，此后每轮同步完成约 10 分钟再运行下一轮。同步只请求成交、资金流水和持仓，使用独立于交易循环的后台任务。交易币种和 AI Learning 共用最近一次成功的结果，页面每分钟读取一次。

账本位于配置文件同目录的 `data/reconciliation/<trader_id>.json`，兼容旧版独立对账工具的文件。账本包含带币安 ID 的流水和时间进度，查询或持久化失败时页面继续显示上次成功的数据。首次同步完成前页面显示原有 NOFX 统计和同步状态。可删除账本让 NOFX 在下次同步时重建普通接口可查历史。

首次同步回填约三个月。更早的流水可以放在 `data/reconciliation/archive/<trader_id>.json`。归档需要包含 `trader_id`、`from_ms`、`through_ms_exclusive`、`fills`、`income`，两类流水的结构分别与币安 `userTrades`、`income` 一致，覆盖区间须与现有账本或普通接口的查询区间相接。NOFX 每次同步检查归档。

页面计算 USDT 合约已平仓交易的净盈亏和胜率，使用 USDT 成交盈亏、USDT 手续费和能唯一归属到单笔的资金费。其他资产费用保留在账本中。币安成交覆盖范围、未配对平仓、未归属的资金费和其他资产手续费在页面标示。币安账户如果还有人工交易，也会出现在账户成交统计中。持仓未归零时，成交和费用保留在账本，整笔交易于归零后纳入胜率。

策略继续使用 `trade_memory/<trader_id>/trades.jsonl` 中的历史。页面中的币安展示结果不参与模型决策或风控。
